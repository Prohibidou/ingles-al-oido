# Inglés al oído

Webapp de repaso hablado del banco de frases en inglés. Cada tarjeta dice la
consigna en español, deja una pausa para contestar en voz alta y después suena la
frase en inglés, con el texto sincronizado en pantalla.

- 13 pistas · 376 tarjetas · 1 h 46 min de audio.
- Instalable desde Android: **Agregar a la pantalla de inicio**.
- Funciona sin datos una vez guardada desde el botón de la pantalla de inicio.

Generada con los scripts de `anki/` del proyecto `subtitulos`.
